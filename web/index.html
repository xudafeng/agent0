Connect your model

Use your own API key to get started. Settings are saved on this computer.

Keys are stored in a local .env file and sent only to your selected provider. Saving starts a new conversation.

Jev routing

Let Jev select relevant tools while your main model handles reasoning and replies.

When Jev is uncertain or unavailable, the main model chooses from all tools.

When enabled, conversation context, memory, and tool descriptions are sent to TypeSafe. Your key is stored locally. Saving starts a new conversation.

Start a new conversation?

This clears the current chat and task plan. Your saved memory stays.

MCP servers

Connect local or remote MCP services. Enabled services connect when a conversation needs them.

Saving, enabling, or removing a server starts a new conversation. Your memory stays.

Status is based on the last connection check.

The built-in demo server is always available.

Filesystem

Read, write, and organize files in your chosen folder. Bundled with agent0; no installation needed.

Only this folder and its subfolders are accessible. Save to enable access.
